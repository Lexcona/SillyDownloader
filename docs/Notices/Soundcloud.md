# 9-16-26 (DRM Update)
Currently some of the songs on SoundCloud are being moved over to being DRM only, now I have some theories on how to get around this, there is a very high chance that some songs on SoundCloud will not be able to be downloaded with this tool.

For anyone wondering, all the DRM is, that for anything other than the MPEG formats, is encrypted in AES. Thankfully they make it easy to decrypt, downside it would require me to create a playlist format downloader which isn't hard until you combine the clips which I will most likely do with ffmpeg.

Until then if a song doesn't download I will recommend using yt-dlp since that project (which is ALOT better than this nonsense) has support for SoundCloud.
